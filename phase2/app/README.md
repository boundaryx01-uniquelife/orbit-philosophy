# 2단계 쇼핑 대화 · 로컬 검증

이 화면은 기존의 고정 상품 비교 페이지를 대체하는 첫 대화 흐름이다. 휴대폰과 태블릿 브라우저에서 일상 대화나 쇼핑 질문으로 시작할 수 있다. Telegram을 연결하면 두 채널이 같은 대화 기록을 쓴다. 사용자가 별도로 허용한 경우에만 에이전트가 먼저 질문할지 판단한다.

## 실행

저장소 루트에서 Python 3.11 이상으로 실행한다. 의존성 설치는 없다.

```bash
export PHASE2_MODEL_API_KEY='개인 키'
export PHASE2_MODEL_NAME='사용할 OpenAI 호환 모델명'
python3 -m phase2.app.server
```

기본 주소는 `http://127.0.0.1:8767`이다. 키와 모델명을 설정하지 않아도 화면·기록 조회는 열리지만, 실제 답변 전송은 비활성화된다. 별도의 호환 API를 사용하는 경우 `PHASE2_MODEL_API_URL`에 서버 측 채팅 완료 주소를 설정한다. 서버는 기본적으로 로컬 컴퓨터에서만 접속할 수 있다. 테스트용 합성 모델은 `node phase2/test_ui.cjs`에서 일시적으로 띄우며 실제 구매 판단에 쓰이지 않는다.

Telegram과 웹 검색은 선택 사항이다. Telegram BotFather에서 만든 봇의 토큰과 사용자 이름을 서버 환경 변수에 넣고 **별도 프로세스**로 작업자를 실행한다.

```bash
export PHASE2_TELEGRAM_BOT_TOKEN='비공개 봇 토큰'
export PHASE2_TELEGRAM_BOT_NAME='at 없이 봇 사용자 이름'
export PHASE2_SEARCH_API_KEY='비공개 Brave Search API 키'
python3 -m phase2.app.telegram
```

브라우저에서 `현재 맥락 → 연결 코드 만들기`를 누르고 Telegram 봇에 `/start 코드`를 보낸다. 코드는 10분 후 만료되며 한 번만 쓸 수 있다. 연결 뒤에도 먼저 말 걸기는 기본적으로 꺼져 있다. 웹에서 켜거나 끌 수 있고, Telegram의 `/pause`는 능동 발신을 끈다. `/unlink`는 연결을 끊는다. 웹 서버와 Telegram 작업자는 **같은 `PHASE2_DB`**를 사용해야 한다. 개발용 로컬 웹 서버를 공개 인터넷에 노출하지 않는다.

검색 키를 설정하면 현재 가격·후기·비교 같은 문장에서 Brave 웹 검색 API 요약을 최대 3개 사용한다. `PHASE2_SEARCH_API_URL`은 합성 테스트용 호환 엔드포인트에만 바꿔 쓴다. 검색 요약은 원문이나 실시간 가격을 검증하지 않았다고 표시한다. 키가 없으면 검색하지 않는다. 실제 모델·검색·Telegram 호출은 각각 제공자에게 해당 요청 자료를 전송하므로, 실자료 시험 전에 제공자 조건을 확인해야 한다.

기본 데이터베이스는 `phase2/data/phase2.sqlite3`이다. 다른 위치는 `PHASE2_DB`로 지정한다. `phase2/data/`, `phase2/.private/`, `.env`는 Git에서 제외한다. **실제 대화·건강 정보·상품 주문 내역·인증 키를 공개 저장소나 테스트 로그에 넣지 않는다.** 모델 API를 연결하면 입력 대화와 확인된 맥락은 해당 모델 제공자에게 전달된다. 제공자의 데이터 처리 조건을 확인하기 전에는 실자료를 사용하지 않는다.

## 현재 동작

- 일상 이야기 또는 한 문장 쇼핑 질문으로 시작하고, 관련 분야를 추정하거나 사용자가 고른다.
- 이전 대화와 확인된 기억 중 해당 대화, 해당 분야, 또는 사용자가 전체 적용을 확인한 내용만 다음 요청에 전달한다.
- 모델이 제안한 기억은 사용자가 확인·수정·삭제할 수 있다. 반응, 실제 구매 여부, 사용 후 결과는 서로 다른 필드다.
- 링크는 `본문·가격 미확인`으로 표시한다. 서버 저장 실패와 AI 연결 실패는 오류로 보여주며, AI 실패 시 답변을 지어 저장하지 않는다.
- 익명 브라우저 세션마다 데이터 접근을 분리한다. 새 브라우저나 다른 기기는 다른 공간으로 시작한다.
- Telegram 봇은 일회용 코드로 한 브라우저 공간에 연결한다. 동의한 경우에만 최근 대화에서 근거 있는 질문 하나를 선택해 먼저 보낸다. 모델은 침묵할 수도 있다.

## 아직 필요한 작업

이 서버는 로컬 검증용이다. 로그인 없는 두 브라우저의 자동 병합이나 계정 복구, 실제 상품 페이지 수집·가격/후기 검증, 이미지 첨부, 대화별 여러 제안에 대한 개별 피드백, 운영 배포와 개인 자료 업로드는 구현되지 않았다. 브라우저 쿠키를 지우면 Telegram 연결이 남아 있어도 웹 공간을 다시 찾을 수 없다. 현재 대화 피드백은 대화 하나에 한 세트로 저장한다. Telegram 수신의 장애 재시도는 중복이나 누락 가능성이 있어 운영용 전달 보장이 아니다. 실제 서비스에서는 제안별 기록과 본인 확인·백업·삭제 정책을 설계해야 한다. 외부 API 실연결은 토큰과 네트워크 접근이 없어 확인하지 못했다.

## 검증

```bash
python3 -m unittest phase2.test_flow -v
node phase2/test_ui.cjs
```

두 테스트 모두 합성 대화와 임시 데이터베이스만 쓴다. 브라우저 테스트는 Playwright와 Chromium이 있는 개발 환경에서 390/820/1280px 폭을 확인한다.
