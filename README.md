# ORBIT Philosophy

> 생각을 저장하는 곳이 아니라, 생각이 어떻게 바뀌어 가는지를 기록하는 프로젝트.

ORBIT Philosophy는 인간과 AI가 함께 대화하고 만들고 판단하는 과정에서
**무엇을 만들었는가보다 왜 그렇게 생각했는가**를 남기기 위한 장기 프로젝트다.

## Working Rule

1. 철학을 기능보다 먼저 둔다.
2. 중요한 대화와 판단의 맥락을 버리지 않는다.
3. 문서는 완성본이 아니라 버전으로 진화한다.
4. AI는 정답 기계가 아니라 사고를 비추는 거울이자 협업자다.
5. 프로젝트가 커져도 출발점의 질문을 잃지 않는다.
