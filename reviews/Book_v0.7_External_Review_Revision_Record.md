# 전체 원고 v0.7 — 외부 검토본 수정 기록

> Date: 2026-10-01
> Status: EXTERNAL REVIEW

## 수정 범위

| 위치 | 수정 | 이유 |
|---|---|---|
| 제4장 | 학부모 설명회 준비에서 사용한 실제 작업 조건을 바탕으로 장면과 요청문을 재구성했음을 밝힘 | 재구성된 문장을 당시 대화의 직접 인용이나 완전히 독립적인 허구로 오해하지 않도록 함 |
| 제7·9장 | 설명회 사례가 제4장에서 시작됨을 명시하고 기록 예시도 같은 재구성 사례로 표기 | 장 사이 연결 오류와 사례 출처의 모호함 수정 |
| 제9장 | 제4장의 목차 교정에서 확인되지 않은 ‘도구 소개 확대 제안’ 서술을 실제 이해 여부와 자료 출처의 미확인 사항으로 바꿈 | 앞 장면에 없는 제안을 후속 기록에 추가하지 않도록 함 |
| 제5·8·9장 | 별도 양식처럼 보이던 목록을 본문 설명이나 제7장의 기록으로 연결 | 독자가 모든 장의 목록을 각각 작성해야 한다는 부담을 줄임 |
| 웹 교정판 | 원고 밖에 외부 독자를 위한 검토 안내를 추가하고 v0.7 저장 키를 분리 | 무엇을 표시하면 되는지 알리고 이전 판본의 브라우저 교정본이 섞이지 않도록 함 |
| 웹 진입점·제작 문서 | 독자용 페이지의 편집 기준 문장을 제거하고 깨진 수정 기록 링크를 갱신 | 본문 밖의 판본 안내도 현재 결정을 따르도록 함 |

## 유지한 방향

첫 결과물은 검토의 시작점이며, 의미 확인과 사실·작동 검증은 다르다. 판단권은 문제 제기자에게 있지만 LLM의 해석과 근거 있는 반론도 실제 판단 재료로 다룬다. 결정과 합의를 구분하고 선택의 이유와 남은 차이를 다시 사용할 수 있도록 기록한다. 이 내용은 외부 독자의 동의를 얻기 위해 변경하지 않았다.

서문의 출처·한계, 원자료 인용의 편집 주, 제6장의 파트너·판단권 구분, 제10장의 완성·완결 구분은 유지했다. 작업 지시나 판본의 편집 목적을 원고 본문에 다시 넣지 않았다.

## 외부 검토에서 확인할 것

- 초보 독자가 사례의 실제 조건과 재구성된 대화의 경계를 이해하는가?
- 제4장의 확인 방법과 제7·9장의 기록을 서로 다른 상황에 필요한 도구로 읽는가?
- 제6장의 LLM 반론과 인간의 최종 판단을 어느 한쪽의 형식적인 선언으로 받아들이지 않는가?
- 설명이 막히거나 지나치게 반복되는 위치는 어디인가?

외부 검토본은 독자의 반응을 받을 수 있는 판본을 뜻한다. 사용자 자신의 의미 판단과 독자의 실제 읽기 결과까지 확인했다는 선언은 아니다. 공개 웹사이트 배포와 PDF 갱신은 별도 작업으로 남아 있다.
