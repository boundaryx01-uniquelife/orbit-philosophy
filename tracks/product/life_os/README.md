# Life OS — 로그인 없는 첫 챗 화면

첫 제품 경험의 중심을 **대화**로 확인하는 합성 사례 시제품이다. 화면을 열면 로그인이나 설문 없이 바로 질문을 보낼 수 있다. 답변은 현재 확인된 것, 모르는 점, 다음 질문 또는 조심스러운 제안 **하나**, 그 이유를 한 대화 안에서 보여 준다. 반응의 의사 표현, 실제 실행, 뒤의 체감은 각각 별개다.

## 실행

Python 3.12 이상으로 저장소 루트에서 실행한다.

```sh
python3 tracks/product/life_os/server.py
```

`http://127.0.0.1:8765`를 연다. 포트가 필요하면 `LIFE_OS_PORT`로 바꿀 수 있다. 서버는 루프백 주소에서 정적 파일과 합성 fixture만 제공한다. 로그인, API 키, 외부 AI 호출, DB, 업로드 또는 쓰기 API는 없다.

## 화면에서 해볼 일

1. 빈 챗창에 한 장면이나 질문을 입력한다. InBody나 자료가 없어도 된다.
2. 답변의 질문 하나를 보고, “왜 이렇게 물었나요?”에서 근거와 한계를 확인한다.
3. “고려해 볼게” 같은 반응을 선택한다. 실행과 체감은 자동으로 완료 처리되지 않는다.
4. 같은 챗창에 이어서 말한다. “지금은 맞지 않아”를 남겼다면 다음 답변은 그 이유를 묻되, 사용자의 영구 성향으로 만들지 않는다.
5. 합성 예시 두 개로 자료 없는 시작과 조건이 다른 신체 자료 비교를 확인한다. “이전 이야기”에서 이 탭의 대화를 다시 열거나 지운다.

## 보호 경계와 아직 없는 기능

- 입력은 **현재 브라우저 탭의 메모리**에만 있으며 서버로 전송하거나 브라우저 저장소에 남기지 않는다. 새로고침하면 사라진다. 실제 건강 자료와 식별 정보는 입력하지 않는다.
- 답변은 합성 시나리오와 제한된 규칙으로 만든 화면 시제품이다. 실제 자료를 AI가 분석한다고 주장하지 않는다. 진단, 인과 추정, 고정 운동 루틴, 자동 행동은 제공하지 않는다.
- 파일 첨부는 아직 열지 않았다. 합성 예시의 Evidence만 대화 안에서 보여 준다.
- 사용자가 정한 순서에 따라 **완성 전 로그인은 만들지 않는다.** 따라서 계정 분리·기기 간 동기화·서버 저장은 지금의 완료 조건이 아니다. 챗 동작을 확인한 뒤, 민감 자료의 취급과 함께 별도 설계·검증한다.

## 검증

```sh
python -m pip install jsonschema==4.26.0
python tracks/product/life_os/model/validate_first_flow.py
python3 -m unittest discover -s tracks/product/life_os -p 'test_flow.py' -v
node --check tracks/product/life_os/static/app.js
node tracks/product/life_os/test_ui.cjs
```

브라우저 검증에는 Playwright와 Chromium이 필요하다. 합성 대화, 근거, 분리된 반응, 이어 말하기, 새로고침 시 삭제를 휴대폰 390px·태블릿 768px·PC 1280px에서 확인한다. [ADR-0001](../../../decisions/ADR-0001_Life_OS_First_Vertical_Slice.md)과 [교정 기록](../../../decisions/CR-0031_Keep_Life_OS_Chat_First_Without_Login.md)에 범위 변경 이유를 남겼다.
