# M01 — 첫 결과는 끝이 아니다

> Version: MODULE MVP v0.1
> Status: SMALL-PILOT READY
> Audience hypothesis: 초등 5~6학년~중학생 LLM 초보 학습자
> Duration: 3차시×40분
> Sources: `C0001`, `C0002`, `C0005`, Philosophy 원칙 1·4·5·6

## 모듈 질문

> AI가 만든 답이 완성되어 보여도 우리는 왜 다시 대화해야 할까?

## 준비

- 교사가 사용할 수 있는 LLM 화면 1개 또는 미리 저장한 응답
- 모둠별 활동지
- 학생이 비교할 수 있는 첫 결과와 수정 결과
- 개인정보를 넣지 않는 공통 과제

### 공통 과제 예시

> 우리 학교 학생들이 쉬는 시간에 더 즐겁게 지낼 수 있는 행사를 계획해 줘.

이 요청은 대상 학년, 장소, 예산, 안전, 참여 인원과 완료 조건이 빠져 있다. 첫 결과가 그럴듯하더라도 학습자가 어긋남을 찾을 수 있다.

## 1차시 — 완성되어 보이는 답 의심하기

### 목표

첫 결과의 보기 좋은 점과 실제 목표에 맞는지를 구분한다.

### 흐름

1. **첫 결과 보기 — 5분**  
   교사가 공통 과제를 LLM에 입력하고 결과를 그대로 보여 준다.
2. **빠른 판단 — 5분**  
   학생은 ‘바로 사용 가능 / 조금 수정 / 다시 만들어야 함’ 중 하나를 고르고 이유를 한 문장으로 쓴다.
3. **탐정 활동 — 15분**  
   모둠은 결과에서 다음을 찾는다.
   - AI가 스스로 정해 버린 것
   - 우리 학교와 맞는지 모르는 것
   - 꼭 필요한데 빠진 것
   - 안전하거나 가능한지 확인해야 할 것
4. **외형과 목표 구분 — 10분**  
   ‘글이 잘 써짐’과 ‘우리 문제를 해결함’을 두 칸으로 나눠 증거를 붙인다.
5. **마무리 — 5분**  
   “첫 결과는 ___이지만 ___은 아니다” 문장을 완성한다.

### 산출물 — 첫 결과 진단표

| 보기 좋은 점 | 목표에 맞는 점 | 어긋난 점 | 아직 모르는 점 |
|---|---|---|---|
|  |  |  |  |

## 2차시 — 대화 깔때기로 뜻 맞추기

### 목표

자신의 목표·경계·완료 조건을 말하고, LLM이 이해한 뜻을 확인해 교정한다.

### 대화 깔때기 카드

| 항목 | 우리 모둠의 내용 |
|---|---|
| 해결하려는 문제 |  |
| 꼭 들어가야 할 것 |  |
| 하지 말아야 할 것 |  |
| 시간·장소·비용 제약 |  |
| 충분히 해결됐다고 볼 조건 |  |
| 아직 결정하지 못한 것 |  |

### 흐름

1. **진단표 다시 보기 — 5분**
2. **깔때기 카드 작성 — 10분**
3. **LLM에게 되말하기 요청 — 5분**  
   “바로 계획을 만들지 말고, 우리가 원하는 목표·꼭 지킬 것·하지 말아야 할 것·완료 조건을 먼저 다시 설명해 줘.”
4. **맞음·어긋남·모름 표시 — 8분**
5. **교정한 뒤 두 번째 결과 만들기 — 7분**
6. **전후 비교 — 5분**

### 교정 문장 틀

- 맞게 이해한 부분은 ___이다.
- ___은 우리가 말한 뜻과 다르다.
- ___은 AI가 스스로 정했으므로 우리가 결정해야 한다.
- 아직 정하지 못한 ___은 모르는 것으로 남긴다.

## 3차시 — 선택의 이유와 남은 차이 기록하기

### 목표

수정 결과에서 하나를 선택하고, 선택 이유의 종류와 남은 반론을 기록한다.

### 근거 카드

| 표시 | 뜻 | 학생용 질문 |
|---|---|---|
| 사실 | 확인한 정보 | 실제로 확인했나? |
| 제약 | 시간·돈·규칙·안전 | 반드시 지켜야 하나? |
| 선호 | 우리가 더 좋아하거나 중요하게 여김 | 우리에게 중요한가? |
| 경험 | 전에 해 본 결과 | 경험에서 무엇을 알았나? |
| 추론 | 정보에서 예상함 | 아직 확인이 더 필요한가? |

### 흐름

1. **두 번째 결과에서 선택지 2~3개 찾기 — 5분**
2. **선택지별 장점·위험·근거 분류 — 10분**
3. **모둠 최종 선택 — 8분**
4. **AI의 반론 또는 다른 제안 확인 — 5분**
5. **미니 Choice Record 작성 — 7분**
6. **첫 결과와 현재 판단 비교 — 5분**

### 미니 Choice Record

- 우리가 선택한 것:
- 가장 중요한 이유:
- 근거 종류:
- 선택하지 않은 대안:
- 그 대안을 고르지 않은 이유:
- AI와 생각이 다른 부분:
- 다시 검토할 조건:

## 평가 루브릭

| 수준 | 목표·경계 | 검증·교정 | 선택 근거 | 남은 차이 |
|---:|---|---|---|---|
| 4 | 목표와 완료 조건을 구분하고 구체적 경계를 제시 | 맞음·어긋남·모름을 근거로 교정 | 여러 근거 종류와 대안 배제 이유를 설명 | 반론과 재검토 조건을 함께 기록 |
| 3 | 목표와 주요 경계를 제시 | 어긋난 부분을 구체적으로 교정 | 선택 이유와 근거 종류를 설명 | 선택하지 않은 대안을 기록 |
| 2 | 목표는 있으나 경계가 모호함 | 좋다·나쁘다 수준으로 판단 | 이유는 있으나 근거 종류가 불명확 | 차이를 단순 삭제하거나 무시 |
| 1 | 결과를 목표와 구분하지 못함 | 첫 결과를 그대로 수용하거나 전부 거부 | 선택 이유를 설명하지 못함 | 다른 관점을 남기지 않음 |

## 교사 관찰 기록

- 학생이 결과의 문장 품질과 목표 적합성을 구분했는가?
- LLM의 오류만 찾는 활동으로 축소되지 않았는가?
- 학생이 자신의 불완전한 요청도 교정 대상으로 보았는가?
- 모둠 내 다른 의견과 LLM의 반론을 함께 다뤘는가?
- 기록 활동이 대화보다 더 큰 부담이 되지 않았는가?

## 파일럿 뒤 수정할 것

1. 40분 안에 실제로 완료하지 못한 활동
2. 학생이 이해하지 못한 용어
3. 정답 찾기처럼 행동하게 만든 질문
4. 개인정보·사실 검증에서 추가로 필요한 안전 장치
5. 학년별로 줄이거나 확장해야 할 기록 양
