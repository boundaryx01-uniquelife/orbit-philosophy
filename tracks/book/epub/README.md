# EPUB Prototype

`dist/First_Output_Is_Not_Completion_v0.8.epub`은 서문·3부 10장·작업 안내를 담은 외부 검토본을 전자책에서 읽기 위한 가변형 EPUB 3 파일이다.

## 다시 만들기

저장소 루트에서 실행한다.

```bash
./tracks/book/epub/build.sh
```

필요 도구는 `python3`, `pandoc`과 `unzip`이다. 빌드할 때 표지 원화가 SVG 활자층 안에 포함되므로 EPUB 밖의 이미지에 의존하지 않는다. 이어 EPUB의 MIME 형식, ZIP 무결성, 필수 파일과 두 시각물의 포함 여부를 검사한다. `epubcheck`가 설치된 환경에서는 표준 유효성 검사도 실행한다.

## 수록 범위

- 이미지형 표지 원화와 별도 조판된 한글 제목·부제
- 전체 3부 10장 구성
- 3부 10장 전체 초안
- 제1장 삽화와 대체 텍스트

제목, 저자 표기와 전체 원고는 확정 전이다. 따라서 이 파일을 출간본 또는 검증 완료본으로 취급하지 않는다.
