# 다시 펼쳐 보는 작업 안내 {.unnumbered}

이 페이지는 본문의 방법을 다시 찾기 위한 안내다. 모든 칸을 매번 채우거나 모든 질문에 답할 필요는 없다. 지금 판단에 필요한 것만 사용한다.

| 언제 | 무엇을 확인하거나 남기는가 | 본문 |
|---|---|---|
| 작업을 시작하거나 방향이 어긋났을 때 | 해결할 문제 / 중요 기준 / 하지 않을 것 / 완료 조건. 모르는 조건은 미확인으로 남긴다. | 제4장 |
| 중요한 선택을 할 때 | 선택 / 이유 / 중요한 대안 / 불확실성 / 재검토 조건 | 제7장 |
| 작업을 멈추거나 다시 시작할 때 | 목표 / 완료한 것 / 확정한 선택 / 남은 차이와 위험 / 미결정 사항 / 다음 시작점 | 제9장 |

결과를 받은 뒤에는 뜻이 맞는지와 사실·계산·작동이 맞는지를 따로 살핀다. 현재 단계를 닫을 때는 처음의 문제, 완료 조건, 남은 한계, 다시 열 조건을 확인한다. 기록의 크기와 확인의 깊이는 선택의 무게에 맞춘다.

## 이 글에서 사용하는 말 {.unnumbered}

아래 설명은 본문을 찾아보기 위한 요약이다. 일반적인 사전이나 모든 AI 작업에 적용할 표준 정의는 아니다.

| 표현 | 이 글에서의 뜻 | 처음 설명한 곳 |
|---|---|---|
| ORBIT Philosophy | 사용자와 LLM의 협업 대화와 기록을 묶은 프로젝트명 | 서문 |
| LLM / 프롬프트 | 대규모 언어 모델 / AI에게 건네는 질문이나 작업 요청 | 서문 |
| 시험용 첫 결과물(MVP) | 핵심 생각을 실제로 시험하고 반응에서 배우기 위해 먼저 만드는 작은 형태. MVP는 제품 개발에서 쓰는 말이지만, 이 글에서는 문서·코드·디자인·계획까지 포함하기 위해 ‘시험용 첫 결과물’이라고 표현한다. | 제1장 |
| 인스턴트적 사고 | 형태가 나왔으니 판단도 끝났다고 여기는 태도 | 제1장 |
| 경계 / 완료 조건 | 하지 않을 일과 넘지 않을 범위 / 지금 단계를 마쳤다고 판단할 기준 | 제1장 |
| 추론 / 되말하기 | 말과 맥락에서 뜻을 짐작하기 / 이해한 뜻을 자기 말로 설명하기 | 제3장 |
| 대화 깔때기 / 통역 | 가능성을 펼치고 덜어내기 / 경험과 우선순위를 작업 기준으로, 제안을 판단 가능한 말로 바꾸기 | 제4장 |
| 의미 확인 / 검증 | 요청의 뜻을 맞추기 / 사실·계산·작동 결과를 근거와 대조하기 | 제4장 |
| 파트너 / 판단권 | 해석과 반론을 성실하게 다루는 협업 방식 / 제기한 문제가 충분히 해결됐는지 판단할 권한 | 제6장 |
| 관계의 기억 | 확인한 뜻과 경계, 선택과 교정을 다음 판단에 사용할 수 있게 남긴 기록 | 제8장 |
| Chronicle / Choice Record | 생각이 바뀐 사건의 기록 / 무엇을 왜 선택했는지의 기록 | 제9장 |
| 완결 | 한계와 재검토 조건을 밝히고 판단과 기록까지 마무리하며 현재 단계를 닫는 일 | 제10장 |
