## `cover-art-v0.1.png`

- 용도: 《첫 답은 끝이 아니다》 EPUB 시제품의 이미지형 표지 원화
- 모드: 새 이미지 생성, 세로형, 불투명 배경
- 핵심 지시: 검은 종이 질감 위에서 서로 다른 두 궤도가 좁은 지점을 통과해 정렬되는 추상 편집 디자인, 흰색·회색 선과 한 번의 주홍색 강조, 상하단 활자 여백
- 배제: 글자, 로고, 사람, 로봇, 뇌, 회로, 채팅 말풍선, 일반적인 SF 인터페이스
- 의미: 합일이 아니라 차이를 가진 두 주체의 의미 조율

## `cover-layout-v0.1.svg`

- 용도: 표지 원화 위에 정확한 한글 제목·부제와 시제품 표시를 올리는 EPUB 3 표지
- 방식: 생성 이미지와 활자층을 분리한 SVG 조판
- 이유: 생성 이미지 안의 글자 오류를 피하고 제목 변경 시 원화를 다시 만들지 않기 위함
- 주의: 현재 제목과 `ORBIT Philosophy` 표기는 최종 저자 크레디트가 아니라 v0.1의 임시 표기

## `chapter-01-first-output-v0.1.png`

- 용도: 제1장 ‘첫 답은 왜 끝처럼 보이는가’의 본문 삽화
- 모드: 새 이미지 생성, 가로형, 불투명 배경
- 핵심 지시: 완성되어 보이는 직사각형 결과물 뒤에 남은 거친 스케치와 어긋난 목표, 결과에서 목표로 이어지는 한 번의 주홍색 교정선
- 배제: 글자, 로고, 사람, 로봇, 뇌, 회로, 채팅 말풍선, 사실적인 사진 표현
- 의미: 완성된 외형이 아직 끝나지 않은 판단을 가릴 수 있음

두 이미지는 같은 흑백·주홍색 계열과 종이 질감을 사용한다. 후속 삽화도 이 어휘를 유지하되, 장 원고가 확정된 뒤 제작한다.
