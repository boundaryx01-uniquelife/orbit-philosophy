# Noto Sans KR Book Subset

웹·PDF 시제품에는 Google Fonts의 `NotoSansKR[wght].ttf`에서 현재 원고에 필요한 글자만 남긴 Regular·Bold 부분 글꼴을 사용한다.

- 원본: Google Fonts `ofl/notosanskr`
- 라이선스: SIL Open Font License 1.1 (`OFL.txt`)
- 생성 도구: `tracks/book/tools/subset_font.py`
- 목적: 한글 깨짐을 막으면서 단일 HTML과 PDF의 용량을 줄임

원고에 새로운 글자가 추가되면 공식 원본 글꼴을 내려받아 부분 글꼴을 다시 생성해야 한다. 현재 저장된 두 부분 글꼴은 v0.2 원고·표지·교정 화면에 맞춘 자산이다.
