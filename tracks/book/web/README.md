# Web Book Prototype

공개 페이지: <https://boundaryx01-uniquelife.github.io/orbit-philosophy/book/>

`dist/First_Output_Is_Not_Completion_v0.10.html`은 서문·3부 10장·작업 안내를 담은 외부 검토본이다. 별도 서버 없이 브라우저에서 바로 열 수 있으며 글꼴, 표지와 본문 삽화를 파일 안에 포함한다.

## 다시 만들기

저장소 루트에서 실행한다.

```bash
./tracks/book/web/build.sh
```

화면 폭이 넓으면 목차가 왼쪽에 고정되고, 휴대전화에서는 목차가 본문 위로 이동한다. 상단 진행 막대와 맨 위로 이동 버튼 외에는 읽기를 방해하는 인터랙션을 넣지 않았다.

## 읽으며 교정하기

`교정 시작`을 누르면 본문 문장을 직접 수정할 수 있다.

- 수정 내용은 현재 브라우저의 `localStorage`에 자동 저장된다.
- 새로고침해도 같은 브라우저에서는 교정본이 유지된다.
- `Markdown 내려받기`로 수정한 전체 원고를 파일로 내보낼 수 있다.
- `원문으로 복원`은 확인 뒤 브라우저의 교정본만 지우며 저장소 원고를 변경하지 않는다.
- v0.10는 새 저장 키를 사용하므로 이전 판본의 교정 내용이 새 원고에 덮이지 않는다.

공개 웹 페이지가 GitHub 원고를 직접 덮어쓰지 않게 한 것은 실수로 원자료가 바뀌는 것을 막고, 교정본을 검토한 뒤 선택적으로 반영하기 위해서다.
