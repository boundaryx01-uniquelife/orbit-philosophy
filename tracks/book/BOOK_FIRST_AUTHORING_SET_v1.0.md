## v1.0의 의미

v1.0은 이 책의 서문, 3부 10장과 작업 안내를 하나의 원고로 쓰는 **1차 저작을 마쳤다**는 기준점이다. 지금까지 합의한 방향과 수정 원칙을 반영한 내용을 고정해, 이후 작업에서 어디가 왜 달라졌는지 비교할 수 있게 한다.

이 이름은 출간·유통·최종 조판까지 끝났다는 선언이 아니다. 최종 제목과 저자 표기, 실제 독자 검증, 휴대전화·전자책 앱 표시, PDF 인쇄 조판은 별도 단계로 남아 있다. 이 경계는 완성본이라는 말을 약하게 만들기 위한 단서가 아니라, 이번에 무엇을 실제로 끝냈는지 정확히 밝히기 위한 것이다.

## 포함한 원고

- 서문 「이 이야기의 시작과 한계」와 「이 판본에 대하여」
- 제1부 「완성처럼 보이는 첫 결과물」 3장
- 제2부 「대화를 판단의 과정으로 바꾸기」 4장
- 제3부 「다음 판단을 처음부터 시작하지 않기」 3장
- 작업 안내와 용어 찾아보기

각 장의 개별 파일명과 내부 버전은 집필 이력을 보존하기 위해 그대로 둔다. v1.0은 이 파일들을 한 시점의 승인된 구성으로 묶은 **원고 세트 버전**이다.

## 완성 판본

| 형식 | 파일 | 역할 |
|---|---|---|
| 반응형 웹 | `web/dist/First_Output_Is_Not_Completion_v1.0.html` | 기본 읽기·후속 교정본 |
| EPUB 3 | `epub/dist/First_Output_Is_Not_Completion_v1.0.epub` | 전자책 앱·리더기용 판본 |
| Markdown | `epub/dist/First_Output_Is_Not_Completion_v1.0.md` | 전체 원고 확인·재사용 기준본 |

세 파일은 같은 원고에서 만들며, 내용이 다른 별도 판본으로 편집하지 않는다.

## 1차 저작에서 확정한 것

1. 중심 문제는 생성 속도 자체가 아니라, 그럴듯한 첫 결과물에서 판단을 멈추거나 서로 다른 뜻을 확인하지 않은 채 작업을 이어 가는 데 있다.
2. 사용자가 최종 판단권을 갖되, AI의 해석·반론·한계를 판단 재료로 진지하게 다룬다.
3. 실제 대화와 가상 사례를 구분하고, 이 대화에서 만든 표현은 보편 용어처럼 제시하지 않는다.
4. 전문 용어는 처음 설명하고 이후에는 문맥에 맞는 쉬운 표현을 우선한다.
5. 선택과 교정의 이유를 기록해 다음 대화를 처음부터 시작하지 않게 한다.

## 다음 단계

2단계는 [용어 체계화](TERMINOLOGY_SYSTEMATIZATION.md)다. v1.0 원고 전체에서 반복되거나 비슷하게 쓰인 말을 찾아 다음 세 층으로 정리한다.

- 본문에서 쉬운 말로 풀어 쓸 표현
- 책의 논지를 위해 반복해서 사용할 핵심어
- 부록에서 배경과 차이를 자세히 설명할 용어

용어를 바꾸더라도 원래의 문제의식이나 남아 있는 반론을 조용히 삭제하지 않는다. 의미가 달라지는 수정은 단순 편집으로 처리하지 않고 별도 판단과 기록을 남긴다.

## 다시 열 조건

- 새로운 원자료가 발견되어 출발점이나 인용 범위를 고쳐야 할 때
- 용어 체계화 과정에서 장 사이의 실제 모순이 발견될 때
- 실제 독자가 중심 주장을 반복해서 다르게 이해할 때
- 기기·형식 검증에서 읽기를 막는 문제가 확인될 때
