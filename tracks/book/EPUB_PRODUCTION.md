# ORBIT Book — EPUB Production Note

> Version: v0.1
> Status: PROTOTYPE PIPELINE
> Working title: 《첫 답은 끝이 아니다》

## 이번 판본의 목적

이 EPUB은 출간 완료본이 아니다. 현재의 제목 가설, 3부 10장 구성과 제1장 샘플이 실제 전자책 화면에서 어떤 읽기 경험을 만드는지 확인하기 위한 제작 시제품이다.

검증할 것은 세 가지다.

1. 긴 문장이 작은 화면에서도 무리 없이 읽히는가.
2. 삽화가 내용을 대신 설명하지 않고 핵심 질문을 다시 보게 하는가.
3. 표지의 상징이 ORBIT의 관계와 조율을 진부한 AI 이미지 없이 전달하는가.

## 형식 원칙

- EPUB 3의 가변형 본문(reflowable)을 사용한다.
- 한글 제목은 이미지 생성에 맡기지 않고 전자책의 문자 조판으로 표시한다.
- 장식용 이미지를 늘리지 않는다. 각 부의 전환 또는 핵심 개념에 필요한 삽화만 둔다.
- 모든 삽화에 대체 텍스트와 짧은 캡션을 둔다.
- 흑백 화면에서도 의미가 남고, 주황색은 강조 신호로만 사용한다.
- 표지와 삽화에서 로봇, 인간형 AI, 뇌, 회로, 채팅 말풍선 같은 관습적 상징을 피한다.

## 표지 콘셉트

서로 다른 방향에서 온 두 궤도가 좁은 지점을 통과하며 하나의 정돈된 관계를 만든다. 이는 한쪽이 다른 쪽에 흡수되는 합의가 아니라, 차이를 가진 채 의미를 맞춰 가는 과정을 상징한다.

현재 표지는 제목과 저자명이 확정되기 전의 `v0.1`이다. 생성된 원화에는 글자를 넣지 않았으며 EPUB 안에서 정확한 한글 제목과 부제를 별도 조판한다.

## 삽화 운용안

전체 원고에서는 우선 부별 1점, 총 3점을 기준으로 한다.

| 위치 | 핵심 이미지 | 역할 |
|---|---|---|
| 1부 | 완성된 외형과 어긋난 목표 | 첫 결과가 사고의 끝처럼 보이는 착각 |
| 2부 | 서로 다른 두 표식과 그 사이의 좁은 통역 지대 | 차이를 지우지 않는 의미 조율 |
| 3부 | 끊긴 궤적을 이어 주는 기록의 표식 | 다음 판단이 처음부터 시작되지 않게 하는 기억 |

2부와 3부 삽화는 해당 원고가 생긴 뒤 제작한다. 먼저 이미지를 완성하고 글을 맞추는 순서를 피하기 위해서다.

## 빌드와 검증

저장소 루트에서 다음 명령으로 시제품을 다시 만들 수 있다.

```bash
./tracks/book/epub/build.sh
```

빌드는 `pandoc`으로 EPUB 3 파일을 만든 뒤 ZIP 구조, 필수 메타데이터, 목차, 이미지 포함 여부를 검사한다. 별도의 `epubcheck`가 있는 환경에서는 최종 유효성 검사도 수행한다.

## 아직 결정하지 않은 것

- 최종 제목과 부제
- 인간 저자·공동 저자·프로젝트명의 표기 방식
- 유통 플랫폼과 ISBN
- 고정형 표지 이미지에 한글 서체를 포함하는 최종 조판
- 전체 원고 분량과 삽화의 최종 수

EPUB 이후 추가된 웹·PDF 판본과의 역할 비교는 [`FORMAT_MATRIX.md`](FORMAT_MATRIX.md)에서 관리한다.
