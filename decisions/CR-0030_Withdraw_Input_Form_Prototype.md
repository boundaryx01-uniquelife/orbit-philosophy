## 실제 교정

사용자: “아! 이런걸 만들고 싶은게 아닌데.. 이 내용은 글로도 충분함.. 원래 우리가 만들려고 했던 프로그램이 뭐였는지 기억 나지 않아?”

AI가 `MVP_SPEC.md`의 Brief → Mirror → Funnel → Decision → Checkpoint를 프로그램의 핵심으로 해석하고, 정보를 입력해 재개 기록을 내려받는 클릭 시험본을 만들었다. 그 해석은 사용자 의도가 아니었다. 해당 시험본과 3회 시험 안내는 현재 제품 경로에서 철회한다. 이전 원본은 Git 이력에서만 추적할 수 있다.
