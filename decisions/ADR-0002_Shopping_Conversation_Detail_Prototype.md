# ADR-0002: 쇼핑 상세 시제품의 대화 저장 방식

- 날짜: 2026-10-06
- 상태: 시제품 선택. 운영 서비스 선택은 아님.

## 맥락

첫 제품 범위는 쇼핑 판단 한 건의 상세 화면이다. 사용자가 대화에서 밝힌 구매 목적과 우선 조건이 이후 비교의 근거가 되어야 한다. 테스트 중 로그인은 사용성을 해치므로 두지 않는다. 공개 저장소에는 실제 개인 자료를 두지 않는다.

## 선택

Python 표준 라이브러리 HTTP 서버와 SQLite로 **로컬 합성 시제품**을 만든다. 브라우저는 반응형 단일 HTML로 구성해 파일을 직접 열어도 첫 화면의 예시가 보이게 한다. 서버를 통해 접속하면 발화 원문, 역할, 시각, 적용 구매 건, 명시적 우선 조건을 저장한다. 판단 조건은 가장 최근의 유효한 사용자 선택 발화에 연결한다. 수정 이력은 해당 발화에 연결하고 삭제 시 함께 삭제한다. 제안 반응, 실제 구매, 사용 뒤 체감은 별도 필드에 저장한다.

자유 문장의 의미를 임의로 확정하지 않는다. 현재 시제품은 사용자가 선택지로 명시한 우선 조건만 판단에 적용한다. 모든 상품·가격은 합성 자료이며 판매처 접근이나 외부 AI 호출은 없다.

## 결과와 다음 결정

로컬 서버의 모든 창이 같은 합성 사례를 공유한다. 따라서 이번 시제품은 대화 누적·정정·재접속 흐름은 검증하지만 계정 분리와 실제 기기 간 동기화는 검증하지 못한다. 실사용 단계에서는 계정별 접근 제어, 인증, 전송 보호, 삭제·백업 정책, 상품 정보 수집의 허용 범위를 별도 ADR로 결정해야 한다. 현재 서버를 네트워크 서비스로 배포하지 않는다.
