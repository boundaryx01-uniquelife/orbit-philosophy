# Choice Record — CR-0031

> 상태: 사용자 교정 / 적용
> 날짜: 2026-10-09

## 교정

사용자는 첫 구현을 보고 “또 예전의 실패한 형태로 돌아온 것 같다”고 지적했다. 이어서 **메인은 챗이며 완성되기 전까지 로그인은 만들지 않기로 했다**고 다시 확인했다.

## 잘못 판단한 부분

AI는 이슈 #1의 Case·Evidence·Claim·피드백·계정 기준을 화면의 개별 입력 양식과 가입 화면으로 옮겼다. 기능 항목은 충족하려 했지만, 대화를 중심에 두라는 사용자 의도와 [CR-0030](CR-0030_Withdraw_Input_Form_Prototype.md)의 철회 이유를 지키지 못했다. 로그인과 계정 동기화를 너무 일찍 구현했다.

## 적용

- 첫 화면을 질문과 응답이 이어지는 **하나의 챗**으로 바꾼다. 근거와 불확실성은 대화 속 응답에서 보이며, 입력 설문을 만들지 않는다.
- 로그인·계정·DB·업로드·서버 쓰기 API를 현재 시제품에서 제거한다. 합성 입력은 현재 탭 메모리에만 둔다.
- 이전 이야기와 반응 수정은 탭 안에서만 검증한다. 새로고침 복구와 기기 간 동기화가 되는 것처럼 말하지 않는다.
- 합성 규칙 응답은 실제 AI 분석으로 표시하지 않는다. 챗 형태를 사용자와 확인한 뒤 인증·저장·자료 취급을 다시 설계한다.

이 교정은 이슈의 장기적인 보호 기준을 폐기하지 않는다. **순서와 현재 화면의 범위**를 바로잡는다.
