# Choice Record — CR-0028

> Status: `DECIDED / APPLIED`
> Date: 2026-10-01
> Issue originator: 현재까지의 저작 작업을 완성본으로 정리해 저장하고 2단계로 진입하자는 사용자 판단
> Final decision owner: 사용자

## 선택 또는 판단

《첫 결과물이 곧 완성은 아니다》의 서문·3부 10장·작업 안내를 **1차 저작 완성본 v1.0**으로 묶고 1단계를 닫는다. 다음 2단계는 `CR-0027`에서 뒤로 미뤄 둔 전체 용어 체계화로 시작한다.

## 선택한 이유

- 원고는 서문부터 제10장까지 하나의 흐름을 갖추었고, 외부 피드백과 초보 독자 관점 검토에서 확인된 명백한 수정 사항을 반영했다.
- LLM과 MVP의 첫 설명과 이후 쉬운 호칭까지 정리해, 내용과 문장의 1차 기준점을 만들 수 있게 되었다.
- 계속 같은 층위에서 문장을 고치면 저작 단계와 용어 편집 단계의 경계가 흐려지고, 무엇이 언제 바뀌었는지 비교하기 어렵다.
- 전체 문맥이 생긴 뒤 용어를 체계화하자는 앞선 결정의 시작 조건이 충족되었다.

## 완료 범위

- 서문, 3부 10장, 작업 안내와 현재 용어 찾아보기
- 공통 원고에서 만든 웹·EPUB·Markdown v1.0
- 1차 저작 세트 문서, 릴리스 검토와 아카이브 기록

## 포함하지 않은 것

- 출간·판매·유통 결정
- 최종 제목과 저자 표기 확정
- PDF 최종 조판과 인쇄 검수
- 실제 독자 3명 이상의 반응 검증
- 휴대전화와 복수 전자책 앱 표시 검증

이 항목은 1차 저작이 미완성이라는 뜻이 아니라, 서로 다른 검증과 제작 단계로 남긴 일이다.

## 2단계 경계

- 전문 용어, ORBIT 내부 표현, 정밀하게 쓰는 일상어를 구분한다.
- 본문에서 풀어 쓸 말, 반복할 핵심어, 부록에서 자세히 설명할 말을 나눈다.
- 용어 변경이 원래 주장이나 반론을 바꾸면 단순 편집으로 처리하지 않는다.
- v1.0은 비교 기준으로 보존하고 2단계 수정은 다음 버전에서 진행한다.

## 재검토 조건

- v1.0 빌드가 공통 원고와 다르거나 필수 장·자산이 빠졌을 때
- 원고 안에서 중심 주장과 직접 충돌하는 문장이 발견될 때
- 사용자가 1차 저작의 완료 범위를 다시 열기로 판단할 때
