# ADR-0001 — Life OS 첫 세로 흐름

> 상태: 첫 구현 선택 · 2026-10-05

## 맥락

공개 Genesis의 Evidence → State → Constraint → Decision → Chronicle 흐름을 작은 합성 사례로 확인한다. `tracks/product/MVP_SPEC.md`의 대화 깔때기는 철회된 AI 가설이며 이 구현의 요구사항이 아니다. 사용자 요구로 질문만으로 시작하고, 반응·실행·효과를 구별하며, 한 계정의 여러 기기에서 같은 기록을 보아야 한다.

## 선택

- 반응형 웹 한 벌을 PC·태블릿·휴대폰에 제공한다. 서버에서 계정별 JSON을 저장하고 클라이언트는 주기적으로 다시 읽는다.
- Python 표준 라이브러리 HTTP 서버와 SQLite를 사용한다. 로컬에서 추가 서비스나 패키지 계정이 필요 없고, 트랜잭션과 계정별 조회를 직접 검증할 수 있다. SQLite 파일과 첨부는 공개 저장소 밖 또는 무시 경로에 둔다.
- 비밀번호는 salt를 둔 scrypt 해시로 저장하고, 임의 세션 토큰의 해시만 DB에 저장한다. 변경 요청은 same-origin 및 CSRF 토큰으로 보호한다. 서로 다른 기기 사용은 동일한 HTTPS 서버에 접속한다는 전제가 있다.
- 모델 호출 없이 제한된 규칙으로 **제안 또는 질문 하나**를 만든다. 이를 AI의 관찰이나 의학적 진단으로 가장하지 않는다. Evidence의 출처·시점, 관찰 Claim과 추론 Claim, 모르는 점을 분리한다.
- 반응의 평가, 실제 실행 여부, 체감 결과는 별개 필드다. `고려해 볼게`는 실행·효과의 증거가 아니다. 과거 반응은 현재 사례의 참고 맥락일 뿐 고정 성향으로 일반화하지 않는다.

## 범위와 재검토

첨부는 파일 그대로 계정별 저장하며 자동 추출·해석하지 않는다. 공개 저장소에는 합성 자료만 둔다. 이 서버는 첫 작동 흐름의 로컬 검증용이다. 실서비스 전에는 운영 인증, HTTPS 종료, 백업·삭제 정책, 접근 감사, 의료 정보 취급 및 모델 사용 여부를 별도로 검토한다. 현재 구현은 의학적 판단이나 행동 자동 실행을 제공하지 않는다.
