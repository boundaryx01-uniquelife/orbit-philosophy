# Choice Record — CR-0026

> Final decision owner: 사용자

## 선택 또는 판단

원고가 완성 단계에 들어갈 때까지 PDF 생성을 중단하고, 반응형 웹판을 기본 읽기·교정 환경으로 사용한다.

## 적용 범위

- 공개 페이지의 기본 행동을 `읽으며 교정하기`로 유지한다.
- 공개 페이지에서 PDF 내려받기 선택지를 제외한다.
- GitHub Pages 빌드에서 PDF 복사를 제외한다.
- EPUB은 전자책 환경을 확인하기 위한 보조 판본으로 유지한다.
- 이미 만든 PDF v0.3은 파이프라인 검증과 비교를 위한 체크포인트로만 보존한다.

## 선택한 이유

현재 단계의 핵심은 페이지 조판이 아니라 문장과 장의 흐름을 반복해서 읽고 고치는 일이다. PDF는 원고가 바뀔 때마다 다시 생성해야 하고 화면 반응도 느려 교정 주기를 길게 만든다. 웹판은 바로 열리고, 문장을 직접 수정하며, 교정본을 저장하고 내보낼 수 있어 현재 목적에 더 맞다.

## PDF 재개 조건

- 전체 원고의 장 구성이 완료됨
- 큰 폭의 문장 이동과 삭제가 줄어듦
- 고정 지면·인쇄·최종 조판을 검토할 필요가 생김

세 조건이 충족되면 기존 PDF 파이프라인을 현재 원고에 맞게 갱신하고 전 페이지 시각 검증을 다시 수행한다.
