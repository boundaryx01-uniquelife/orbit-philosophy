# Choice Record — CR-0027

> Status: `DECIDED / APPLIED`
> Date: 2026-09-30
> Issue originator: 용어를 먼저 정리하기보다 현재 방향과 수정 원칙을 유지해 제10장까지 진행하고, 전체 초안이 생긴 뒤 체계화하자는 사용자 판단
> Final decision owner: 사용자

## 선택 또는 판단

용어 체계화는 제10장까지의 전체 초안을 완성한 뒤 진행한다. 지금 단계에서는 독자가 이해하지 못할 정도로 막히는 표현만 본문 안에서 풀어 쓰고, 용어집이나 고정된 명명 체계는 만들지 않는다.

## 선택한 이유

- 전체 문맥이 생기기 전에 용어를 고정하면 뒤 장의 역할에 맞지 않는 정의를 만들 수 있다.
- 현재 우선순위는 3부 10장의 논리와 읽기 흐름을 한 번에 확인할 수 있는 원고를 확보하는 것이다.
- 실제로 반복되는 말과 독자가 막히는 지점은 전체 원고에서 더 정확하게 찾을 수 있다.

## 적용 범위

- 제4~10장을 현재 철학과 앞선 수정 방향에 맞춰 작성한다.
- Chronicle·Choice Record처럼 처음 등장하는 내부 명칭은 일상어로 먼저 설명한다.
- 전체 초안 교차검토에서는 용어 문제를 삭제하거나 확정하지 않고 후속 검토 항목으로 모은다.
- 웹·EPUB v0.4는 ‘전체 첫 초안’이며 출간 또는 최종 승인 상태로 보지 않는다.

## 재검토 조건

전체 10장을 한 흐름으로 읽은 뒤 다음을 검토한다.

1. 같은 뜻에 여러 표현이 쓰였는가.
2. 일상어와 ORBIT 내부 용어의 경계가 불분명한가.
3. 초보 독자가 앞 장으로 돌아가지 않고 이해할 수 있는가.
4. 본문에서 풀어 쓸 말과 별도 용어 안내가 필요한 말을 구분할 수 있는가.
