## 의미

‘인스턴트적 사고’는 결과가 빠르게 만들어지는 기술 자체를 비판하는 말이 아니다. 프롬프트를 입력하면 나온 첫 결과를 완성이라고 생각하고, 이후의 대화·검토·수정을 생략하는 태도에 대한 경고다.

MVP는 작동 여부와 방향을 확인하기 위한 출발점이다. 첫 결과가 있어야 인간과 LLM은 구체적인 대상을 보며 서로 다르게 이해한 부분, 놓친 의미, 넘은 경계와 필요한 수정을 발견할 수 있다.

## 기본 작업 자세

```text
프롬프트
  → 첫 결과 또는 MVP
  → 서로가 이해한 목표와 의미 확인
  → 어긋남·과잉·누락 발견
  → 경계와 방향 조정
  → 수정된 결과
  → 다시 확인
```

이 과정에서 완성은 한 번에 생성되는 산출물이 아니라, 대화를 통해 목표와 의미를 계속 맞춰 가며 접근하는 상태다.

## 구분해야 할 것

| 구분 | 인스턴트적 사고 | ORBIT의 작업 자세 |
|---|---|---|
| 첫 결과 | 완성 | 대화의 시작점 |
| MVP | 제출 가능한 끝 | 검증과 개선의 출발점 |
| 대화 | 결과를 얻기 위한 입력 | 목표와 의미를 맞추는 과정 |
| 수정 | 최초 답변의 실패 | 상호 이해가 깊어지는 정상 과정 |
| 완성 | 한 번에 도착하는 상태 | 반복적으로 접근하는 상태 |
